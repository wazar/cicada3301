# Proposed first puzzle experiment — not executed

Test whether a small, explicit set of already-solved key recipes transfers to the
start of two unsolved LP2 pages under the particular reset/skip model we can test.
This is a control-gated **bounded recheck**, not a claim these recipes were never
tried. Earlier family-wide exclusions do not document this complete validated setup.

Rationale: complete known-solution fixtures demonstrate DIVINITY, the literal rune
key FIRFUMFERENFE, and prime-totient arithmetic. The prime/totient instruction is an
actual solved clue. Their transfer to unsolved pages is an explicit hypothesis,
not a fact about a common cipher, language, or key across the book.

Freeze four 2,048-symbol key arrays: repeating DIVINITY; repeating
FIRFUMFERENFE (retain the documented F spellings); ascending primes beginning2
reduced mod29; and those primes minus1 reduced mod29. Use the reference alphabet
and store exact arrays/hashes. Two arithmetic signs give eight recipe/sign
combinations. Test rigid and the measured legacy beam400/max_skip3 separately at
only offset0, resetting key and filter state at each page. No aliases, variants,
new seed transforms, key offsets or parameter tuning.

Real-input scope, only after controls: first120 rune indices of original LP2
0.jpg and1.jpg, taken from frozen inputs-v1 and recording slice hashes. Retain
all16 decode choices per page, their complete rune arrays, scores and alignments.
The joint hypothesis requires a shared recipe to work on both pages; its failure
would not reject different per-page ciphers, keys, continuous state or other text.

Before real input, use the actual four low-entropy/structured candidate arrays
on fresh known messages. Require all20 planted two-page cases for each recipe to
include the planted recipe/sign among the top-scoring tied hypotheses and recover
every rune exactly under that hypothesis. Preserve ties and equivalent arrays;
use recipe ID only for display ordering, never to claim unique identification. Uniform-random-key
success in PARALLEL-01 does not substitute for this gate. A failed gate blocks
this experiment's negative interpretation; stop without running the puzzle slice
or tuning away the failure, and propose a separate instrument task.

For each fixed recipe AND sign, select the better decoder on each page and take
the weaker of those two page scores. Maximize this joint statistic across the
eight fixed recipe/sign hypotheses; do not mix signs or recipes between pages.
Calibrate the
maximum over the **entire recipe/sign/decoder set** on100 independent negative
pairs; then use another100 held-out pairs without altering the rule. Negatives
must include fresh English encrypted with independently generated keys outside
the set, with identical lengths/reset/rejection rules; add a histogram-preserving
shuffle panel as a separate sensitivity analysis, explicitly noting that shuffling
destroys repeats. Save seeds and full outputs. Do not claim these surrogate
families exhaust real-input nulls.

A provisional flag requires each page >=-5.5 and the joint statistic above the
calibration maximum +0.5. No held-out flag is permitted to certify the gate;
if any occurs, stop and report failed calibration. Even zero in100 leaves an
approximately2.95% one-sided95% upper bound under that negative distribution.
Report that uncertainty; this is a shortlisting experiment, never automatic proof.

Stop after this fixed scope, any control failure, or the finite budget. Start
with a <=300-second pilot; permit at most one named <=1,800-second main batch
only after its measured cost is recorded. No adaptive extension. Any puzzle flag
requires complete readable output, re-encryption, independent interpretation and
new held-out page controls before it can be called evidence of a solution.
No flag means only no candidate passed this exact small experiment. Broader
running-key/number-theoretic families remain open outside its bounds.
