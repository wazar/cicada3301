## Commands and execution controls

Read-only inspection used `git status`, `git diff`, `rg`, `sed`, `cat`, `nl`, and
short `.venv/bin/python -B` JSON-reading scripts. Some long tool displays were
truncated; targeted follow-up reads and stored full selected ledger entries supplied
the source details used in the register. These displays are not research run logs.

`build_t1_register.py` reads source/JSON as text, constructs the register, checks
referential integrity, and writes only audit files. It neither imports research
modules nor launches tests/searches. It ran with the existing Python 3.12 virtual
environment, one worker and an external 300-second subprocess timeout. Its exact
command, actual exit code, duration and separate stdout/stderr are retained in
`runs/T1/build-command.json` and sibling log files. No stochastic computation was
performed, so no T1 random seed applies.

The artifact generator is not a repaired T0 runner. Later checks validate only the
new audit records and preserved file hashes; they are not regression experiments.
