# Frozen model/control specification

Only three full solved keyed reference groups are read. Their interruption labels are one-based F occurrence numbers, not rune positions. Independent subtraction modulo 29 must reproduce every expected rune while tracing input/output position, F occurrence, key before/after and emitted rune. Literal F retains output length; deletion and rejected-key-draw filtering are different models.

Synthetic controls use finite, explicit keys with encryption c=(p+k) mod29. Declared interrupted plaintext F emits c=F without consuming k. Ordinary ciphertext F is deliberately present too. Two tiny fixed controls include zero-key ambiguity; four larger controls use three fixed prose messages and a seeded random rune message, with seeded random finite keys and forced ordinary encrypted F sites. Cases are selected without examining scores. No puzzle/unsolved input enters search.

Exact enumeration assigns each observed F either normal consumption or literal-F non-consumption, independently of the truth labels. Independently written prefix expansion, with no pruning, must produce precisely the same path/plaintext/key-index set on tiny cases. Larger cases also retain complete exhaustive compatible outputs. Beam widths 2, 16, 128 rank prefixes by normalized English transliteration quadgram score (data from existing table, independently implemented scoring). All boundary-score ties are retained; width is a target, not a hard cap. No merging of paths or guessed interruption count. Full path, not just key state or plaintext, defines survival.

For every beam, report true path represented by model, first pruning position, survival, exact-path rank and top-score ties, whether any tied top plaintext is exact and whether all tied top plaintexts are exact. Ground truth is evaluated only after search. No scorer preference establishes truth or uniqueness. Record compatible path and distinct plaintext counts separately. No acceptance threshold or real-puzzle calibration is claimed.

Seed 330101; four processing commands maximum, each <=300 seconds, <=1200 seconds total. Pilot: references plus tiny enumeration/beam agreement. Main: four larger controls. A failed assertion stops progression pending a preserved task-code correction. Standard library only; no inherited Python imported. Only the English count table is reused as scorer input. No production edits or unsolved decoding.
