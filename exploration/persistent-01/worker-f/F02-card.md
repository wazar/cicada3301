# F02 / OB-ROLES — frozen before execution
Assumption challenged: every discovery page has the same output role/register. Alternative: contiguous page regions encode different kinds of objects, reflected in complete token lengths and terminal symbols, even if rune-unigram entropy is flat.
Input: F01 discovery-only source maps, keeping exact original identities. No reserved contents; edges join only originals differing by one. No broad annotation reads.
Transform: each page becomes (a) eight-bin word length histogram (1..7,>=8), (b) length-by-terminal-rune histogram (8*29 bins). Normalize and use squared Hellinger distance. Two fixed statistics: negative mean distance over contiguous observed page pairs, so higher means regional clustering. Page identity is permuted across the same available positions, retaining all within-page streams, lengths, transitions, histograms and sample sizes. No rune shuffle.
Null: 1999 uniform page permutations, seed2026091712; retain all permutations and both statistics. Two-endpoint Bonferroni. Different sample sizes can affect histogram distances; page permutation preserves those sizes globally but not association with position, so a significant result would require size-controlled follow-up and new prediction.
Controls: eight each of baseline common multinomial token encoder, grouped two-state length encoder, grouped terminal-symbol encoder, both; 499 permutations each. Use actual page word counts. Role assignment original<28 versus >=28 fixed beforehand. Length alternatives concentrated in1..3 versus6..8 bins; terminal symbols concentrated0..6 versus22..28. Per-token samples independently emitted by given page-state. This tests explicit stationary page roles, not every structured-output hypothesis; no English or additive decoding.
First executable: f02.py via existing logged <=900s process. STOP/deadline guard. Output all page histograms, raw statistics, permutations and control samples.
Next two tests if null: explicit separator type (hyphen versus period) finite-state test using phase rotation; inspect original0 redheader exact coordinates to freeze image-grounded extraction only if coordinator delegates that distinct channel.
