# J01 — swap-to-anchor ciphertext-driven permutation
Strategy outside-box-v1; SHA256 eac5f90b963597464862cadbd2f8245375c844d2d0b6f9e52f418bcad617517c.
Assumption challenged: full-length additive pad plus rejection is necessary to explain suppressed doubles. Alternative: fixed 29-position alphabet A, emit A[p], then exchange emitted value and A[0]. This update depends only on ciphertext and existing alphabet; no key stream, rejection, insertion or deletion. Repeat at t iff p[t]=0. This differs from C1 rank deletion and C2/C3 move-to-front (a transposition rather than shifting all preceding positions), C4 disjoint-pair fractionation and G09/G10 linear generators.
Motivation: observed repeat deficit; cheap inverse construction, not a claimed source clue. The SECOND prediction is stable skew in inverse source frequencies which predicts a withheld final third of each discovery page. Initial alphabet after first emission is canonically [c0, other symbols ascending]; any other alphabet amounts to a fixed relabeling of 28 non-anchor source indices. Thus categorical entropy and predictive likelihood cover all fixed initial alphabets without searching them. Full continuation is decoded consuming ciphertext; prediction is explicitly a probability distribution, never an exact next-rune forecast.
Q1: hit = aggregate held-suffix categorical log-likelihood above repeat-conditioned whole-procedure null, p<=.01, plus measured source-control detection. Prefix length floor(2n/3); exclude first symbol and all decoded anchor positions; add-one 28-category smoothing. Score sum log(28*(prefix_count[x]+1)/(prefix_nonanchor_count+28)). Each page has separately learned distribution, summed log evidence primary. Individual page p values descriptive only, Bonferroni 5 if promoted. Persist full decoded outputs/source maps, IoC*N, min32 distinct, zlib ratio, entropy, lag mutual information; no language models used or non-English score invented.
Q2: simplicity and repeat deficit only; low-prior completeness test labelled as such.
Q3: ONE mechanism, ONE canonical representative per page; initial alphabets quotiented exactly, no tuning/search. Pages 0,1,3,7,17 only. 999 null replicates, preserving each page's EXACT binary repeat indicator pattern, choosing each nonrepeat successor uniformly among 28 alternatives. This null is conditional on observed repeat schedule, so the second predictor cannot merely exploit that schedule. Exact input hashes/logging retained.
Q4: conditional negative covers swap-to-anchor transition, all fixed initial alphabets through relabel invariance, plaintext with stable nonuniform marginal frequency across prefix/suffix. It does not cover compressed/uniform plaintext, different transpositions, unknown rune units, state resets or arbitrary spelling shifts. Control register: nine known solved rune texts plus shuffled versions; this is categorical, not English-register recognition. Exact encoder/inverse and initial-relabel identity checked on every control; source rune28 rotated to anchor0, convention immaterial to primary statistic. Each control gets 199 exact-repeat-pattern nulls and detection p reported; no claims beyond measured power.
Q5: kill if exact recovery/relabel property fails; no real test until fixed. If control detection fails, call underpowered instead of negative and redirect after at most two extensions.
First execution: standalone J01 script under run_logged.py, single thread <=900 seconds. STOP/deadline checked before real and each null batch.
Next: independent scalar replay if positive; otherwise change mechanism to position-driven involutive alternating rotor whose distinct prediction is parity-conditioned frequency.
