# N01–N02: opaque bijections on pairs

The frozen shared-pair frequency model did not predict continuation of discovery originals0,1,3,7,17. Validation chose phase1; final-quarter pair-minus-baseline gain was **−229.3714 nats**, full-procedure fitted anti-repeat null **p=.8925** (399 replicates). Phase0's unused test gain was −206.8216; it was not substituted for the validation choice. No plaintext or key candidate emerged, and no reserved material was read.

This genuinely tests arbitrary841-label pair substitutions through an invariant: recurrent source pairs remain recurrent opaque ciphertext pairs. It does not fit letter substitutions, Hill matrices, disjoint alphabets, C5 carrier projections, or delimiter word codebooks. Narrow prior checks are recorded in N01-CARD.md. Two phases and one fixed prior strength were considered; no extension to3-rune units followed the miss.

Each control used99 full-procedure null replicates (minimum attainable p=.01); detection required p<=.01 and positive suffix gain. These are small sensitivity panels, **not independent-language trials**: three keys and two phases reuse each of two fixed plaintext panels. Exact-length panels are nonoverlapping slices of the concatenated nine solved sources, with source maps and any dummy/omitted rune retained. Pure controls have repeat rates .0213–.0581; replacement controls .000819–.013923. Repeat replacement changes pair labels, so that row measures robustness of a corrupted pair mechanism and is not a gate on the pure hypothesis. Uniform pair sources remain unidentifiable.

Scope of the miss: one **shared pair alphabet across five page resets**, phase0/1, stable source-pair distribution, and sufficient concentration like these controls. Distinct alphabets per page, local changing distributions, overlapping/polygraphic transducers, pair insertions/deletions, homophones, and compressed/uniform sources remain outside it. The fitted null simulates each page's own smoothed rune marginal and adjacent-repeat suppression; it models, rather than exactly preserves, the observed deficit. Nonstationary/higher-order alternatives and fitted-null estimation uncertainty are not covered. These pages were already discovery inputs, so p is exploratory rather than untouched confirmation.

Independent scalar replay reconstructs each pair's841-category normalized probabilities and reproduces both validation and test scores. All random bijections round-trip source pair labels. Every pair carries both original rune positions; phase tails and pairs crossing split boundaries are explicitly discarded and recorded. No English or non-English LM score enters the test; there are no decrypted outputs to assign language metrics.

Decision: demote only stable, shared opaque pair substitution for these discovery pages at this sample size/source concentration. Do not declare arbitrary polygraphic enciphering excluded. The parent can choose a materially distinct lane; expansion to trigrams is not justified by this miss.
