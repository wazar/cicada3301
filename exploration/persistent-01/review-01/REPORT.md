## Limits and small corrections

1. **C3 raw-control retention:** `ob_c3.py` computes a 200-element held-control `hnull` list but does not save it. Its reported held p=1/201 cannot be independently recounted from retained raw statistics. The main real nulls are saved and checked. Persist that array in a labelled deterministic evidence-recovery run if the held-control tail is published as independently reproducible evidence; this does not require new search coverage.
2. **C4 naming:** `min_error_fraction_any_partition` is a lower bound on same-partition *transition violations*, not a minimum rune-edit fraction. Editing one rune can affect two transitions; avoid the unspecific phrase “45% errors needed.” The existing boundary note correctly states the construction and graph limit.
3. **Permutation assumptions:** E02, E04 and E06 all shuffle page runes, destroying the observed anti-repeat process. Their empirical p-values are conditional on this null, not probabilities for arbitrary anti-repeat encoders. The E report explicitly names this for E06; carry it into E02/E04 interpretation too. C1/C2 include a repeat-rate-matched generative null, but it is still uniform nonrepeat Markov output and does not condition on exact rune histogram or exact repeat count.
4. **Shared input and parsing:** C's controls share `p03_frozen.parse` and the solved-rune reference source ancestry; E's word cells share the existing raw-line transcription. Synthetic encode/decode agreement cannot validate those texts or line breaks. E06 treats each regex run per raw line as a word, so line-wrapped words can be split; summed symbols and adjacent-word statistics inherit that choice. No new transcription defect was demonstrated.
5. **Register and fitting freedom:** C1–C3 avoid the legacy English score, but their positive controls still use the solved-reference English register. Other high-entropy or compressed sources remain undetectable by their entropy/MI tests. E's single strong fixtures are capability examples, not general sensitivity estimates. Separate source-group labels are not independent image witnesses. No heldout reveal is warranted by any reviewed result.
