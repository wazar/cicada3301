# Classic JSteg source provenance

Two targeted archive downloads returned identical8878-byte `jpeg-jsteg-v4.diff.gz` files; `sources.json` records exact URLs, retrieval times and both compressed/unpacked SHA256. Both unpacked copies identify the1993 source patch. Agreement between mirrors establishes byte consistency, not cryptographic author authentication.

The copies remain local for source inspection and reproducibility. The retrieved patch contains attribution but no explicit redistribution grant in its text, so the full archives/diffs are not included in this publication. Independently authored implementations, exact source identities, bounded source-port notes and measured outputs are published. Retrieve either recorded URL and verify both hashes to reproduce source inspection.

The modern `lukechampine/jsteg` project was also inspected as a possible reference, but its CLI header was not substituted for this classic format. The actual old source, its README and host integer semantics can differ; P11/review16 document those differences explicitly.
