# Q08 — longest-match token dictionaries with binary merges

The P24 pair-coverage certificate also contradicts a broader, precisely defined variable-token representation: one shared 29-token longest-prefix dictionary containing any binary merge while retaining both child tokens, followed by an arbitrary fixed bijection to runes. This is a theoretical generalization of the earlier exact GP-renderer obstruction, not independent new ciphertext coverage or a language-wide exclusion.

For a dictionary token w=uv with distinct child tokens u,v, the output pair u,v cannot occur: w would be a longer first match. If u=v, the distinct output pair u,w cannot occur because its concatenation begins with w=uu. Other longer entries cannot rescue either pair: they also prevent u from being the first output. Nonempty distinct dictionary entries ensure that u and w are different tokens. At least one directed nonself token pair is therefore forbidden.

The reconstructed F06 graph has all 812 directed nonself pairs among 8,111 within-word edges from 2,355 admitted units. Any shared rune bijection preserves this contradiction. All 836 observed pair types retain exact page, word, rune and source-character witnesses. No permutation or dictionary search is necessary.

Controls use 24 random binary-merge dictionaries with two/three base symbols and four retained merges each. All 42,396 source strings of lengths 1–7 obey the predicted forbidden-pair constraints. A source-backed A–Z+TH/HE/IN dictionary also round-trips a documented solved passage after GP transliteration and random 29-token relabeling. A separately implemented trie parser replays every saved control and a direct source reconstruction checks every actual pair witness. These are separate implementations by the same coordinator; fresh-agent review remains pending.

An initial run incorrectly selected ASCII words directly from a runic solved file, yielding zero source-backed words while exiting 0. Root inspection caught this before publication. The original run/code/outputs remain in initial-empty-source-control; the corrected control converts through the documented GP table and asserts nonempty input. Artificial controls, actual graph and theorem were unchanged. The original empty fixture is not represented as a successful source-backed control.

Scope excludes per-page changing vocabularies/maps, nonbijective homophones, hidden parser resets inside observed units, nongreedy or rank-priority tokenizers, dictionaries deleting merged children, arbitrary prefix-free dictionaries, or tokens that are not concatenations of two retained entries. It does not rule out compression in general. This resolves the narrow READY-TOKEN proposal without fitting arbitrary dictionaries or using an English score. No new reserved input, key search, image or external corpus was used.
