# Q01: marker-parity alphabet switch gives no held predictive gain

The training-selected marker is rune index13. Its held log-predictive gain is **−0.00312251074 nats per nonrepeat transition**, with complete-procedure conditional-null tail **.205** (199 null panels). It predicts worse than the global baseline. This is not a plaintext candidate or evidence for a control rune.

The alternative mechanism is one in-band rune toggling a two-state alphabet at each occurrence, with state0 at page start. All29 possible markers are evaluated. Each state has arbitrary rune weights rather than an additive shift or an English model. Training uses23 discovery pages;22 different discovery pages supply the score. These pages have already been examined in other experiments and are not untouched validation. Marker selection uses training gain only. Every marker's training, held and per-page scores and weights is retained.

The exact adjacent-repeat mask is conditioned on, so repeated destinations are fixed. At a nonrepeat transition from x, destination y has probability w_state[y]/(1−w_state[x]). The state is the parity of marker occurrences strictly before y, including x. Training weights use nonrepeat destination counts with .5 smoothing per symbol. The baseline uses pooled training counts with the same smoothing. This is a valid conditional predictor, although the count estimator is not an exact maximum-likelihood fit under the excluded-previous-symbol normalization. The complete null/control procedure uses that identical estimator. The test does not explain why repeats are rare.

Twelve actual-size controls use two permuted Dirichlet weight vectors and a uniformly chosen true marker, with the observed repeat masks imposed. Six concentration.5 and six concentration2 controls all recover their planted marker and beat every one of their19 fitted-baseline nulls (minimum tail.05). Held gains range.06350–.25109 nats/nonrepeat. This establishes power for these distinct two-alphabet fixtures; not all switching alphabets, weak differences, multiple markers, other state rules or page-specific models. The controls are not natural-language decryptions.

Nulls use each panel's fitted global weights while preserving every page length and repeat-mask position. They change symbol histograms and other dependencies. Each regenerates the complete29-marker training selection and held prediction. The real .205 is an exploratory conditional-model comparison, not a global significance statement after all research choices.
