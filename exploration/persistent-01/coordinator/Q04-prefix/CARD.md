# Q04-prefix — complete shallow binary prefix alphabet

Assumption challenged: a rune is an encrypted linguistic character. Alternative: rune labels name variable-length binary codewords in a complete binary prefix code, transporting unbiased bits. With29 leaves and maximum codeword length5, exactly two depth profiles exist: three length4 and26 length5 (weights2/1), or one length3 and28 length5 (weights4/1). Both have total integer weight32. Kraft completeness/tree pruning gives this finite classification. Codeword shapes/order do not alter these probabilities under independent fair bits. Arbitrary unknown rune assignments are permitted.

This is a compact format hypothesis, not evidence that the source is compressed or random. A maximum depth5 is an explicit economy assumption; deeper codes, biased/correlated bits, arithmetic coding and state-varying codebooks are outside scope. Existing JPEG Huffman table work concerns image encoding, not rune-level prefix transport; narrow prior-card search found no identical test.

To avoid merely rediscovering low repeats, condition on each actual page's exact adjacent-equality mask. At a repeated slot emit the previous rune; otherwise draw from codeword weights excluding the previous rune. At page start use the full weights. This can be generated by independent fair bits decoded through the code, rejecting repeats, plus externally supplied forced-repeat slots. It does not explain the mask. Each page resets; one shared code-label assignment covers45 discovery pages.

Frozen held statistic is per-emission log likelihood gain over a uniform29-symbol conditional-mask generator. No English scorer, language corpus, key or plaintext search.
