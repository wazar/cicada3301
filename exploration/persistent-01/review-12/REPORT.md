P05D's emission formula is correct for this one-shot mechanism. Independent exact-rational branch enumeration covers every inside-bin previous symbol and an outside symbol for bin sizes 1–12, totaling 90 cases; each probability distribution sums to one. Current-bin size k gives 1/k when the previous rune is outside it, .17/k for an eligible same-rune repeat, and 1/k+.83/[k(k−1)] for another rune inside that bin. Singleton probability is one. The resulting joint score is a normalized conditional generative likelihood for ciphertext under a fixed codebook and the stated source model. It contains no prior enforcing the control generator's particular bin-size allocation. Failure to rank the actual codebook therefore does not isolate source mismatch from finite-sample ambiguity, codebook flexibility or that prior difference.

## One distinct next executable test

Freeze the existing 16 truth maps and each packet's eight saved alternatives. For each original held length, generate (for example) 100 independent plaintexts from the exact frozen P05 unigram/trigram distribution, encode each with that packet's truth codebook and exact one-shot mechanism, and rank those same nine maps by prefix joint likelihood without any refitting. Preserve source/emission draws and rank margins. This tests whether the known source/emission model gives useful finite-length likelihood discrimination on new data, against fixed previously found alternatives; it is not another optimizer or real-page search. It would separate an observed source mismatch from an inability of the current lengths/objective to discriminate even under its own generative assumptions. Results remain conditional on fixed alternatives, known codebooks, no codebook prior and the frozen source model; they do not establish unknown-key search power. No such next experiment was run under this review.
