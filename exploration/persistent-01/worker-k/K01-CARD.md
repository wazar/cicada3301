# K01 preregistration — arbitrary periodic substitution prediction
Assumption challenged: periodic cipher tests must fit additive keys with a language scorer.
Alternative: a separate arbitrary fixed alphabet permutation at each period phase. Under stable nonuniform source marginals this predicts stable phase-conditioned ciphertext marginals.
Motivation: simple finite mechanism and instrument gap, not a positive artifact prior; inexpensive completeness/instrument test. Prior R04 fits additive mod29 keys with quadgrams; P08 fits additive interrupted keys with rune language scoring. Neither is generic opaque permutation marginal prediction. Narrow LEDGER hypothesis query found no matching measured bound.
Input: pinned dataset and page map, originals0,1,3,7,17 only. Each page trains its own distributions, shared period selected by summed validation likelihood. First floor(N/2) train, next through floor(3N/4) validation, final suffix test. Laplace pseudocount1, periods1..8. No refit on validation. Offset is row relabelling and has no effect; assert this. Select maximal validation gain over period1, ties smaller period. Final statistic summed test gain over period1. No plaintext/key recovery is claimed.
Anti-repeat adjustment: derive suppression lambda from training adjacent repeat rate divided by training marginal repeat expectation; clip to[.01,2]. Every candidate predictive distribution downweights previous ciphertext symbol by lambda then normalizes. This is a probability model, not rejection-clock decoding. Null: fit period1 full-page marginals plus suppression by same formula, simulate homogeneous first-order chains, repeat ALL train/validation/period selection. This is a fitted parametric null; it is NOT exact conditional on histogram/repeat count, and does not account arbitrary higher-order nonstationarity. 399 real replicates,99 per control. Preserve all null rows and seeds.
Controls: nine complete solved rune sources, original/shuffled/circular-rotated source registers, opaque independent random permutations at true periods1,3,8. Save source indices, cipher, all permutations; detection is p<=.01 and testgain>0. Period1 controls measure false periodicity; shuffled registers should retain marginal signal but remove language order; rotated registers test split sensitivity. Small-source limitations reported by source length/period. Three conditionals: periods1..8 phase-fixed alphabets, no insertion/deletion/resynchronization, stationary nonuniform marginal register (no English requirement). Near-uniform registers unidentifiable here.
Q1: hit predicts withheld frequencies and beats whole-procedure null; actual opaque controls measure power. Q2: simplicity/instrument gap only. Q3: eight models, unrestricted fitted29-frequency rows rather than enumerated29! keys. Q4: above. Q5: if most period3/8 controls fail, do not interpret a real miss as exclusion; choose pooled-training extension to test sample bottleneck. Threshold .01 is exploratory (no reserve reveal).
Doctrine output metrics: no decoded outputs exist. Retain ciphertext rune indices and source provenance; IoC*N, minimumdistinct32, compressibility; non-English LM is inapplicable to these probability predictions, explicit null. Counts are model fits and predicted runes, zero decrypts/path expansions.
