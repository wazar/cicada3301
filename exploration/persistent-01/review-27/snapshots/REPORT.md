Unbiased bits therefore predict fixed weight ratios2:1 or4:1 among rune classes, regardless of unknown codeword-to-rune labeling. This exact finite profile classification is checked by Kraft enumeration; it does not cover deeper prefix trees, biased/correlated bit streams, arithmetic coding or changing codebooks.

To test more than the already known repeat deficit, the model conditions on every observed adjacent-equality slot and generates nonrepeat slots with the prefix probabilities renormalized away from the previous symbol.
