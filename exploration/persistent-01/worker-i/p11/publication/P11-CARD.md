# P11: exact integer phi with literal-F key nonconsumption

Strategy outside-box-v1; explicitly an existing-method extension, not alternative-model novelty.
Coverage audit: old R03 searched integer_phi rigid offsets0..127/signs/page+continuous reset. Its literal-F540 cells used only primes,prime_minus_one,Fibonacci offsets0/37. R01's TOTIENTS is prime-minus-one, not integer phi. Therefore all integer_phi page-reset literal-F cells here are uncovered by those matrices; do not count rigid/rejection coverage as new.

Rationale: source SOME WISDOM names totient function; finite exactphi(1),phi(2),... interpretation differs from prime-minus-one sequence. No arbitrary constants/compositions. Assumption retained: additive mod29 with ambiguous ciphertextF that may be literal plaintextF and consume no key. Assumption challenged relative to old integer-phi search: every position must consume a key element.

Frozen space:45 configured discovery pages only, page reset, offsets0..127, signs−1/+1.45*256=11,520 real key/page cells. Exact integer sieve phi[1:15001] computed then mod29; compare hash to R03 pinned array and independently assert first128 values by gcd counting. No continuous-reset extension or image-route crossproduct.

Two independently selected paths per cell: checked overnight A fbeam width256 with English Latin quadgram ranking; frozen C p03_frozen.beam width64 with its same TRAIN five-source rune+boundary trigram model. The second is a distinct scorer, not a non-English register and not independent source evidence. Assert frozen C code/training hashes against its manifest. Both model families searched directly, with no rigid-English admission. Retain16 alternatives/model/cell, all source rune outputs, literal choices, consumed key counts, key-before/key-after word/line boundaries, IoC*N,min32diversity,zlib ratio, English and frozen-rune scores. Exact scalar reencryption checks every retained path. Keys and input payloads stored, no editorial plaintext repair.

Controls before full search: encrypt held-out solved WELCOME under phi offset37/sign−1 and p56_AN_END under offset91/sign+1, with every plaintextF literal, then search the same complete256-key matrix under both adjudicators. Record true-key rank, best-rune accuracy, truth-in-top16, scalar reencryption, and off-key alternatives. These source registers are excluded from C training. Recovery is measured, not assumed and not an all-or-nothing universal gate. If the actual planted key cannot be recovered, diagnose/limit claimed sensitivity before real sweep; no silent widening.

Matched null: one deterministic nonzero-only within-page ciphertext permutation, zeros fixed to preserve literal-branch sites and count. Run identical entire256-key matrix/model/selection/retention over all45 null pages. This is wholeprocedure matched comparison, not a many-replicate significance estimate; no confidence/p-value claim from one null. Save all outputs and statistics for future reinterpretation.

Execution: one process/one numerical thread, <=900s logger; resumable unique per-cell compressed output; STOP/deadline checked per cell. Initial pilot limited to first16 real and16 matched-null cells plus complete controls, measured before larger chunks. Cell ordering offsets-major then signs then page spreads early coverage; checksummed queue persisted. No model tuning on real ranks. Kill/redirect at10% if correct-key planted full-page performance is poor, invalid phi hash, reencrypt failures or projected cost disproportionate.

Negative bounds: specific finitephi offsets/signs/page reset, literalF-only transition (no rejection loop), English quadgram and small solved-rune register. A poor score does not establish no plausible non-English plaintext or no other totient procedure.
