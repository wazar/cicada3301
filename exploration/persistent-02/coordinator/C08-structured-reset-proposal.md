# Same shared feedback seed at the verified major marks

Proposed next construction, not an executed result. It combines A07's third/final major-mark reset rule with C's already tested sum-feedback recurrence. No additional punctuation policies, language models or seed band. C's literal-F version is a separate implementation requiring immutable seed state; this derivation is for NO interruptions inside a segment.

For each segment, reset to the same k-symbol seed s. Its firstk normal positions satisfy P_i=C_i-s_i; later P_i=C_i-sum(previousk P) mod29. Independently reset the zero-seed baseline q at each segment. Define periodm=k+1 offsets x_j=-s_j for j<k and x_k=sum(s). Then P_i=q_i+x_(segment_position mod m), and sum(x)=0. The same x applies to every segment, including a segment shorter than k. This is the existing identity applied with shared initial conditions at fixed source marks.

A reset occurs only after a supplied explicit punctuation token. With the frozen local trigram objective and unchanged scoring context, all ordinary within-segment score factors still involve consecutive phase variables. The only nonlocal coupling introduced at a reset is the first new rune's score: (previous segment's last rune, boundary token, new phase0 rune). That factor involves x_r and x_0. Conditioning on x_0 (and x_1, as C02 already does) turns it into a unary factor in x_r. The second new rune involves boundary/x_0/x_1 and is fixed after that conditioning. Word-boundary scores involve no more phase variables than existing within-segment factors.

Therefore a carefully checked adaptation may preserve the cyclic consecutive-factor suffix bound, adding unary terms conditioned on the first phase. It must not silently treat arbitrary reset positions without explicit punctuation as covered. Avoid double-counting local versus crossing factors; test direct total score against factored total on many independent offset assignments, including short segments, boundary patterns and k2exhaustion. Compare small-k exhaustive optimum and admissible bounds before any actual longer-seed recovery. Same k5–8 band, same two existing models if used; no new scorer. Numerical tolerance/bound qualifications remain.

For prediction, infer one shared seed only from page0, freeze it, and decode pages1/2 using their existing marks and uninterrupted physical page joins. Full-section optimization is a separate discovery fit. An ordinary negative ends this precise branch, not all reset/feedback ciphers. Actual/comparator selections and ranks must use identical horizons and reset policy. The structural motivation is observed punctuation; no solved clue expressly says to reset a feedback seed there.

This construction addresses a measured coverage gap: C04/C07 invariants and C02 optimizations assume uninterrupted recurrence, whereas A07 fixed-key resets do not cover feedback keys. It is not evidence that this construction was intended.
