# C09 — a distributed shared feedback period

Frozen before reading or calculating aggregate actual scores. C07 tested whether any single eligible page/period stood out. Its maximum comparison was ordinary (.535) and its short-source capability varied. This follow-up asks a different, finite question: is there weaker but consistent evidence for the SAME uninterrupted recurrence period across eligible pages? It uses the same411page/k features and saved200-panel arrays. No new keys, periods, pages, model, transcription or decryptions are introduced.

For each k with at least two eligible pages in the existing C07feature list, sum their already-pooled-standardized collision z scores, divided by sqrt(pagecount). Standardize each resulting k-column using its pooled200-panel mean and populationSD, then take the maximum across these k values in each panel. Rank actualpanel0 against199comparator maxima with ties counted conservatively. Every supported k is included; no subset chosen by observed individual values. Equal weights per eligible page. Null remains independent first-rune/equality-mask uniform comparators, not histogram/Fsite-preserving; multiple reused/adaptively selected analyses mean this is an exploratory conditional rank, not global significance.

Controls freeze twelve distributed-language books: four existing716-rune Bsourceexcerpts (Guest/Mill/Shelley/Blake) times k2/5/8. Every page whose existing band includes the plantedk receives an independently selected contiguous source slice of that exact page length and an independent seed of that k. Other page slots receive an independent exact-mask uniform background. Three uniform-plaintext books use the same k values and supported slots. Random(2026092300) generates source slice starts, plaintexts where uniform and seeds in fixed author/k/page order. Input arrays and source hashes are saved before any control scores. Repeated/nested source slices are correlated capability examples, not independent language populations.

Each controlbook has its own frozen comparator seedbase 2026700000+100000*controlindex+1000*page. Baseline background uses seedbase+900;199comparators use seedbase+replicate0..198. Every feature's numerators/denominators and all aggregate scores are retained. Positive controls need not all pass a selected threshold; arithmetic failure blocks, weak sensitivity limits interpretation. Verify panel relabeling/ties and independent scalar aggregation; fresh targeted review before actual summary. For actual, load existing C07arrays unchanged: no repeat search/counting as new coverage.

A large aggregate alone is not plaintext. A promising sharedk would require a separately frozen decoding/continuation prediction; an ordinary outcome gives no rationale for key-length expansion. This covers a common-period construction across the stated eligible units; it cannot exclude different periods per section, interrupted/reset streams, other language statistics or deliberately uniform plaintext.
