# Optional focused follow-up: the Q12 recurrence with an explicit literal-F clock

This is a derivation/proposal, not an executed result or an assertion about the puzzle. It would follow the required uninterrupted Q12 extension and structured longer-seed assessment, only if their results justify addressing a transition-model blind spot. Literal-F non-consumption is observed in complete solved reference groups; that does not prove it coexists with sum feedback in the discovery section.

Specify exactly one construction: the feedback stream excludes literal Fs. A normal emitted rune advances the stream; the first k normal runes use the supplied seed, later normal runes use the sum of the preceding k **normal** plaintext runes. At an observed ciphertext F, a literal branch emits F without advancing that stream or changing its feedback history. Printed boundary tokens affect only scoring. Normal plaintext F still advances and enters history as zero. This is distinct from a construction that includes literal Fs in the feedback window, and from P30 FIFO-head autokey.

For unknown seeds, an exact finite-state maximum can initially branch over29 possible normal plaintext values for each of the first k normal symbols, deriving each seed value as cipher-minus-plaintext. After k, the normal transition is deterministic. Future behaviour depends on (number of normal runes so far capped at k, ordered last up-to-k normal plaintext values, previous two score tokens). At a fixed ciphertext index, histories reaching the same state can merge by the usual n-best criterion. Backpointers reconstruct initial seed and literal decisions. Arbitrary initial seed enumeration is thereby incorporated into the same DP, without enumerating every literal mask separately. The zero-sum periodic-error shortcut cannot be assumed once paths have different feedback clocks.

A practical first bounded implementation would target k2 then k3, unchanged P03 score and the verified716-rune body, with memory/throughput measured on tiny exhaustive examples and complete fresh plants first. Need independent enumeration over seeds AND literal masks on short cases; ordinary F, literal F, consecutive F, boundaries, fewer-than-k normal symbols and seed ambiguity must be covered. No silent state cap or global exactness claim after pruning. Backpointer memory must be budgeted; checkpoint/recompute is preferable to unbounded Python ancestor objects.

Decoding real data would require a fixed narrow new experiment card, matched full-procedure comparators and fresh review. This is a new transition construction at small seed lengths, not a reason to widen arbitrary seeds, change rune data or add another language scorer. A miss bounds only this precise clock model. Preserve the uninterrupted results separately.
