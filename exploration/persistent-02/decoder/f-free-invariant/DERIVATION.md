# Exact domain of the F-free identity

All arithmetic modulo29. A ciphertext symbol different fromF(0) cannot use the literal-F transition. Every position of a maximal nonzero run[a,b) is therefore a normal emission under both supported conventions, irrespective of the unknown interpretation of surrounding cipherFs.

Let k be the seed length. After k normal emissions within this run, at position a+k the seed phase is necessarily complete, even if it was zero on entry. The lastk emitted and lastk normal plaintext symbols are identical from this point onward because all those positions lie in the run. Thus C_i=P_i+Σ_(t=i−k)^(i−1)P_t for all i≥a+k. Subtract consecutive equations only when BOTH are valid: i≥a+k+1. This gives C_i−C_(i−1)=P_i−P_(i−k−1). Both compared plaintext symbols now lie in the run.

Set m=k+1. Define q_j=0 for0≤j<min(m,b−a), and for laterj define q_j=q_(j−m)+C_(a+j)−C_(a+j−1). Induction along each phase yields q_j=P_(a+j)−P_(a+(j modm)). Consequently equality between two qvalues in the SAMErun and SAMEphase is exactly equality of their unknown plaintext symbols. No seed is guessed, optimized or restarted; initial zero qvalues merely choose a coordinate origin for each phase. The firstm symbols can legitimately participate in pairs because later symbols telescope back to them. A run oflength≤m has no such pair.

No relation between different run/phase origins is assumed. They may satisfy unknown global constraints, but this diagnostic neither solves nor exploits those constraints. Pairs never cross a cipherF, even if that cipherF happened to be a normal rather than literal emission. This discards potential information conservatively. Ordinary punctuation is irrelevant because the tested recurrence has no physical resets. A reset inside a run would invalidate the asserted implication unless separately excluded/split; reset constructions are outside this diagnostic.

The first guaranteed recurrence equation is at a+k, but the first guaranteed difference equation with both endpoints inside the run is at a+k+1. Earlier application would need facts about seedphase and external history that are not available. Test evidence includes immature seedphase, early/consecutive literalFs, short runs and alltrue normalFs that accidentally encrypt to ciphertextF and hence force a conservative split.

Pair weights are exact orderedcountsΣN(N−1), not independent-observation counts. The resulting pair events are correlated; no binomial significance calculation is used.
